==================================================
1. PROJECT OBJECTIVE
==================================================

The project is a simple initial Zero Trust Network Access (ZTNA) communication core.

Goal:
Build a secure client/server communication system between two clients based on Zero Trust principles.

Architecture:

    Client A
       |
       | TLS
       v
     Server
       ^
       | TLS
       |
    Client B

After authorization and endpoint exchange:

    Client A <------ encrypted UDP ------> Client B

The server should NOT carry application data after direct peer communication is established.

The project is intended to be:
- Python
- Open source
- Terminal-only
- No GUI
- No third-party/cloud service dependency
- Extensible for future development

3. ORIGINAL PROTOCOL
==================================================

The intended protocol flow is:

1. Client connects to Server using TLS/TCP.
2. Client sends AUTH with username/password.
3. Server authenticates the client.
4. Server sends AUTH_RESPONSE.
5. Server creates a random time-limited authentication token.
6. Server sends TOKEN.
7. Client and peer exchange public keys.
8. Client A requests Client B using PEER_REQUEST.
9. Server verifies the token and access control.
10. Server provides endpoint information for both clients.
11. Both clients perform UDP NAT traversal.
12. Direct UDP communication is established.
13. Clients derive a shared key using X25519 + HKDF.
14. Application data is encrypted with AES-GCM.
15. Server is no longer involved in application data.

Protocol message types:

AUTH
AUTH_RESPONSE
TOKEN
KEY_EXCHANGE
PEER_REQUEST
ENDPOINT_INFO
NAT_PROBE
DATA
CLOSE
